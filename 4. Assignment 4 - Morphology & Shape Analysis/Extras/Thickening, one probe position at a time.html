Thickening, one probe position at a time

Thickening is never computed directly in practice. The set is turned inside out, the background is thinned by one cycle of the eight structuring elements, and the result is turned back. Below, that cycle runs at whatever pace you choose — down to a single 3×3 comparison per step.

Definition
A ⊙ B = A ∪ (A ⊛ B)

The procedure actually used
  1. Form C = Ac
  2. Thin C with the same eight structuring elements
  3. Take Cc — that is the thickened set
  4. Drop any points left disconnected from the body

Why thinning the background thickens the set

Each of the eight structuring elements deletes points that sit on one particular side of the set being thinned. Applied to C = Aᶜ, the cells they can delete are exactly the cells of C that touch A: B1 strips the row of background directly beneath A, B3 the column to its left, B5 the row above, B7 the column to its right, and the four remaining elements handle the corners. Remove one layer of background all the way round, complement, and A has grown by one layer — including into concave notches, which is the whole point of the figure.

The elements are applied in sequence: matches for Bk are found on the result left by Bk−1 and deleted together before Bk+1 begins. That ordering is why the growth is not perfectly symmetric.

Conventions used here, so nothing is hidden

The lattice. The set A is a hand-entered lattice in the spirit of Fig. 9.22(a), not a pixel-exact transcription of the printed plate. Click cells with edit set A on and the whole run is recomputed from scratch.

Outside the window. Everything beyond the drawn lattice counts as background, i.e. as part of C. Without that, the border of the window would be mistaken for a border of the background and eaten away.

One cycle. One trip through B1…B8 equals one layer of thickening. The final stage removes any component of the thickened set not 8-connected to the original A; the counter reports what was actually found, which may well be none.
