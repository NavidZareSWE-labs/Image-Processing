## Overview
This repository serves as a portfolio of practical implementations in digital image processing. The code demonstrates how to analyze, manipulate, and enhance digital images using both spatial and frequency domain techniques. Detailed reports are included alongside the source code to explain the mathematical models, methodology, and results of each implemented algorithm.

## Topics Covered

The projects in this repository cover a wide range of core image processing concepts, including:

- **Point Operations & Pixel Resolution:** 
  Applying pixel-wise intensity transformations to manipulate contrast and brightness, and exploring the effects of spatial resolution and sampling.
- **Histogram Processing:** 
  Analyzing and modifying image intensity distributions, including techniques like histogram equalization and matching to improve overall image quality.
- **Image Enhancement:** 
  Applying spatial filters to reduce noise, sharpen images, and emphasize specific visual features.
- **Edge Detection:** 
  Implementing algorithms and gradient operators to identify object boundaries and sharp intensity changes within an image.
- **Frequency Domain Analysis:** 
  Transforming images using Fourier Transforms to perform complex filtering operations, such as low-pass and high-pass filtering.

## Repository Structure

The repository is organized into directories for different topics or project modules. A typical project folder contains:

- `images/`: Sample input images used for testing and processing.
- `output/`: The output images generated by the scripts.
- `Report.pdf`: A comprehensive document detailing the problem statement, approach, and visual analysis of the results.

## Getting Started

To run the code in this repository, you will need a standard Image Processing environment (e.g., Python with OpenCV, NumPy, and Matplotlib, or MATLAB). Refer to the specific source folders for detailed instructions or requirements related to individual projects.
